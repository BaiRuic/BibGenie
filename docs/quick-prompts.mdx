Quick Prompts are reusable shortcuts for recurring research tasks. Save prompts you use often, insert them quickly into the input box, and adapt them to the current context.

## What Are Quick Prompts Good For?

<Cards>
  <Card title="Paper reading">
    Summarize research questions, methods, contributions, limitations, and future work.
  </Card>
  <Card title="Translation and editing">
    Translate selected text, polish English paragraphs, or adjust academic tone.
  </Card>
  <Card title="Literature reviews">
    Extract claims, generate comparison tables, and organize related work.
  </Card>
  <Card title="Critical reading">
    Analyze assumptions, methodological weaknesses, evidence strength, and reproducibility.
  </Card>
</Cards>

## Create a Quick Prompt

<Steps>
  <Step>
    Open BibGenie and go to **Settings → Prompts**.
  </Step>
  <Step>
    Click the add button to create a new quick prompt.
  </Step>
  <Step>
    Enter a name, prompt content, description, and tags.
  </Step>
  <Step>
    Use the toggle to control whether it appears on the chat page.
  </Step>
  <Step>
    Save your settings and return to chat.
  </Step>
</Steps>

## Use a Quick Prompt

On the chat page, click a Quick Prompt or search for it from the prompt menu. Once inserted, it becomes part of the current input, so you can continue editing it, add context, or specify an output format.

Example:

```text
Based on the paper I added, please use the following structure:
1. Research question
2. Method and data
3. Core findings
4. Limitations
5. How I might cite this paper
```

## Quick Prompts vs Custom Instructions

| Type | Scope | Best for |
| :--- | :--- | :--- |
| Quick Prompts | The current input | Task templates such as summarization, translation, comparison, and extraction |
| Custom Instructions | Longer-term behavior preferences | Response language, tone, role, and formatting preferences |

<Callout type="tip" title="Recommended approach">
  Put stable personal preferences in Custom Instructions and task-specific workflows in Quick Prompts.
</Callout>

## Built-In Prompts and Your Own Copies

BibGenie includes prompts such as **Summarize current paper** and **Compare selected papers**. Open the paper or select the items you want to use; for a comparison, select at least two papers. Insert a prompt and adjust the request before sending it. If the target is unclear, name it or [add context](/docs/add-context).

Built-in prompt text can improve with plugin updates. To customize one, open its card in **Settings → Prompts**, select **Create a custom copy**, edit it, and select **Save copy**. You can disable the original if you only want your copy to appear. The original built-in prompt remains available.

## Set Custom Instructions

Use **Custom Instructions** at the top of **Settings → Prompts** for ongoing preferences, such as response language or writing style. Edit the text and select **Save**. Use Quick Prompts for the task you want to perform now.

For example:

```text
Always respond in English. Use academic writing conventions appropriate for computer science.
```

The default preference is to respond in the same language as your input. You can change it if you want a consistent response language across conversations.

**Reset** restores the default instructions and discards unsaved edits in this field. Custom Instructions guide responses; they do not change model capabilities, grant access to unavailable sources, or replace your approval for library changes.

## Quick Prompt Configuration

Each Quick Prompt has the following fields:

<Cards>
  <Card title="Prompt Name">
    Required. When enabled, this name is displayed as a button above the chat input box.
  </Card>
  <Card title="Prompt Content">
    Required. The text that will be sent to the AI model as context.
  </Card>
  <Card title="Prompt Description">
    Optional. Describes the purpose of the prompt, shown on hover.
  </Card>
  <Card title="Prompt Tags">
    Optional. Used for categorization and filtering when managing many prompts.
  </Card>
</Cards>

## Start Simply, Then Refine

“Summarize the paper I am reading” is a useful starting point. You do not need a long prompt. After the first answer, add the detail that matters to your research:

| Goal | A follow-up you can use |
| :--- | :--- |
| Understand a method | “Focus on the method, data, evaluation measures, and limitations. Mark anything the paper does not report.” |
| Examine an argument | “Explain the main claim, theoretical framework, context, and supporting evidence. Separate the author’s position from your interpretation.” |
| Compare selected papers | “Compare the selected papers by question, approach, evidence, and limitations. Cite each important difference and mark missing information.” |

These are requests you can adapt, not separate product modes. For important claims, open the cited source and verify it rather than relying on the prompt alone.

## Example Templates

Add or specify the papers or passages each task needs. For comparisons, identify the papers and check the source for each important claim; ask BibGenie to mark information that the sources do not report instead of guessing. These are examples to adapt, not separate modes you need to enable.

<Tabs items={['Paper summary', 'Passage explanation', 'Review extraction']}>
  <Tab value="Paper summary">
    ```text
    Read the paper I added and summarize it using this structure:
    - Research question
    - Core hypothesis
    - Method and data
    - Main findings
    - Limitations
    - Relevance to my current research
    ```
  </Tab>
  <Tab value="Passage explanation">
    ```text
    Explain the selected text I added:
    - What is the passage saying?
    - What are the key concepts?
    - How does it relate to the paper's main argument?
    - What should I be careful about if I cite it?
    ```
  </Tab>
  <Tab value="Review extraction">
    ```text
    Extract material from these papers for a literature review:
    - Core claim of each paper
    - Agreements and disagreements between papers
    - Themes that can be synthesized
    - Remaining research gaps
    ```
  </Tab>
</Tabs>
