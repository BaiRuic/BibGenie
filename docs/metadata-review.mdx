Metadata Review & Cleaning is a core capability of BibGenie. Papers imported from various academic websites, PDFs, or generic web extractors often suffer from incomplete metadata (missing abstracts, DOIs, page numbers, or journal titles), all-uppercase titles, missing journal abbreviations, unlinked preprint updates, and truncated author lists.

BibGenie pairs **large language models' scholarly intelligence** with **multi-source authoritative academic databases**. With a strictly read-only review engine, transparent candidate evidence, and visual diff approvals, you can effortlessly maintain a clean and standardized Zotero library.

<Callout type="info" title="100% Read-Only Review & Safe Approval">
  The review phase is strictly read-only and never silently modifies your library in the background. The AI generates a **visual diff preview card** comparing current values against proposed changes. Edits are safely written to Zotero only when you explicitly click "Approve".
</Callout>

## Three Review Modes

Describe what you want to fix in ordinary language, such as filling missing fields or checking whether a preprint has been published. You do not need to memorize mode names. The modes below explain which existing information may be changed; review the proposed edits before approving them.

Depending on your workflow needs, you can instruct BibGenie to run under different modes:

<Tabs items={['blank (Complete Missing, Recommended)', 'lint (Format & Standards)', 'all (Full Refresh)']}>
  <Tab value="blank (Complete Missing, Recommended)">
    **Default mode**. Queries authoritative academic sources to **propose updates only for empty local fields and creators**:
    - Preserves existing non-empty titles, authors, years, and publication titles without overwriting.
    - Fills missing abstracts, page ranges, DOIs, publication titles, or proceedings titles.
    - Ideal for the vast majority of everyday library enrichment tasks.
  </Tab>
  <Tab value="lint (Format & Standards)">
    **Local standardization mode**. Skips external fact retrieval and runs built-in scholarly rules to audit and clean existing metadata:
    - Sentence case normalization for titles.
    - Journal abbreviation standardization using LTWA dictionaries.
    - Precise ISO-639-1 language detection.
    - Identifies publisher domains misplaced in metadata fields.
    - Ideal for items that already have complete data and only need typographical standardization.
  </Tab>
  <Tab value="all (Full Refresh)">
    **Full synchronization mode**. Queries external sources to **compare and propose updates to existing fields, with full author list replacement**:
    - Suited for fixing inaccurate or poorly parsed data from low-quality web imports.
    - Great for updating a preprint after it has been officially published in a journal or conference.
    - *Note: Do not upgrade to `all` solely because fields are missing; use `blank` for missing field completion.*
  </Tab>
</Tabs>

## Safety & Ecosystem Compatibility

1. **Better BibTeX Compatibility**:
   - Many researchers rely on Better BibTeX for LaTeX citation keys. BibGenie's Extra field processor strictly preserves `Citation Key:`, `tex.*`, `bibtex:`, and unstructured notes, never stripping or modifying your citation keys.
2. **Item Type Change Safeguards**:
   - When proposing an item type conversion (e.g., from `preprint` to `journalArticle`), the approval card provides clear warnings of fields that may be mapped or discarded.
3. **Scholarly Intelligence Over Heuristics**:
   - Rigid casing rules often damage technical acronyms, chemical formulas, or library names. BibGenie's LLM context filters out inappropriate heuristic suggestions.
