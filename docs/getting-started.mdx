[BibGenie](https://www.bibgenie.com/) is a Zotero AI plugin for reading papers, searching your library, and organizing references. This guide takes you through installation and your first question about a paper.

<Callout type="info" title="Supported Zotero versions">
  BibGenie supports Zotero 7, Zotero 8, Zotero 9, and Zotero 10. We recommend using a recent Zotero version for the most stable plugin and reader experience.
</Callout>

## Download the Plugin

Go to the [BibGenie download page](https://www.bibgenie.com/download) and download the latest plugin release.

The downloaded file is usually named:

```text
bibgenie-<version>.xpi
```

where `<version>` is the release number.

## Install BibGenie in Zotero

<Steps>
  <Step>
    Open Zotero and choose **Tools -> Plugins** from the menu bar.
  </Step>
  <Step>
    In the Plugin Manager window, click the gear icon in the top-right corner and choose **Install Plugin From File...**.
  </Step>
  <Step>
    Select the `bibgenie-<version>.xpi` file you downloaded.
  </Step>
  <Step>
    Restart Zotero after installation.
  </Step>
</Steps>

## Open BibGenie

Click the BibGenie icon in the Zotero toolbar.

You can also use the menu or your configured shortcut:

- Choose **Tools -> BibGenie** from the menu bar.
- Use the configured keyboard shortcut to show or switch the BibGenie sidebar.

If the shortcut conflicts with Zotero or your operating system, you can change it in [Keyboard Shortcuts](/docs/keyboard-shortcuts).

## Ask Your First Question

A good first task is to start with a PDF paper:

On first launch, BibGenie uses a built-in model by default. You do not need to configure an API key or manually choose a model before asking your first question.

<Steps>
  <Step>
    Open a paper's PDF attachment in the Zotero Reader.
  </Step>
  <Step>
    Type your question, or insert **Summarize current paper** from Quick Prompts. A Quick Prompt fills the input box; review or edit it, then send it. You do not need to add the current paper with `@`.

    ```text
    Summarize the paper I am currently reading: its research question, method, main findings, and limitations. Cite the supporting passages.
    ```
  </Step>
  <Step>
    When the answer includes citations, click one to check the supporting source. A citation may return to a page or passage depending on the available source location; check that it supports the claim.
  </Step>
</Steps>

If the answer is useful, click **Save as Note** on the last assistant message to save it as a Zotero note, then open the note to check its contents.

<Callout type="tip" title="Ask for a clear output format">
  Strong prompts specify both the goal and the expected format, such as "summarize in five bullet points", "use sections for method, results, and limitations", or "turn this into a literature review note".
</Callout>

<Callout type="info" title="Need Help?">
  If the plugin is missing, first check that it is enabled in **Tools → Plugins**, then restart Zotero. If the paper cannot be read, confirm its attachment opens locally and see [Add Context](/docs/add-context). For model or connection errors, use [Troubleshooting](/docs/error-in-bibgenie).
</Callout>

## Sidebar and Separate Window

You can use BibGenie in the Zotero sidebar or in a separate window. Both views provide the same research tools; choose based on how much space you need for reading and conversation.

| View | When to use it |
| :--- | :--- |
| Sidebar | Keep BibGenie beside the paper while you read, ask short follow-up questions, and check citations. |
| Separate window | Give long answers and comparison tables more room, keep the PDF wider, or place the conversation on another monitor. |

To switch from the sidebar, click the button with the tooltip **Open in separate window** in BibGenie's top bar. In the separate window, use **Move BibGenie back to Zotero sidebar** to return.

## Updating BibGenie

BibGenie checks for updates automatically when Zotero starts. When a new version is detected, an update button appears in the BibGenie menu bar — click it to install the latest release.

You can also enable automatic updates through Zotero's Plugin Manager:

<Steps>
  <Step>
    Open Zotero and choose **Tools -> Plugins**.
  </Step>
  <Step>
    Select BibGenie in the plugin list.
  </Step>
  <Step>
    Set **Allow automatic updates** to On. Zotero will then update BibGenie automatically when new versions are available.
  </Step>
</Steps>

## Next Steps

For another task, describe your goal and the papers, collection, or other context you want to use. You can add known materials or ask BibGenie to search your library. Follow up to refine the result, and review any proposed library changes before approving them.

You can also select several items in Zotero's library list and ask, “Compare the methods in the papers I have selected.” BibGenie can check your current reader or selection and retrieve the relevant content as needed. For figures, tables, or scanned pages, you can ask it to inspect the relevant PDF page as an image using an image-capable model. See [Add Context](/docs/add-context).
