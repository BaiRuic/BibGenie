BibGenie can do more than read papers. It can help organize your Zotero library by managing tags, creating collections, moving items, and editing metadata.

<Callout type="warning" title="Preview before applying changes">
  BibGenie can inspect your library and discuss a plan without changing it. Actions that write to your library require approval. Read the proposed changes and affected items before approving; a plan written in the conversation is not confirmation that the changes have already run.
</Callout>

## Choose What May Change

Start with the selected items or a named collection and describe the result you want. Include any boundaries: reuse existing tags, preserve collection membership, or leave metadata unchanged.

The same Zotero item can belong to several collections. Say whether papers should be **added to another collection** or **removed from their current collection as well**; do not assume “move” means the same thing in every request.

## Supported Organization Tasks

| Task | Examples |
| :--- | :--- |
| Tag management | Add, remove, and list tags |
| Collection management | Create collections, list collections, move items |
| Metadata editing | Edit title, abstract, publication title, DOI, and related fields |
| Metadata reading | Inspect authors, year, attachments, notes, and tags |
| Literature classification | Group papers by topic, method, year, or project |

<Callout type="tip" title="Need Multi-Source Academic Metadata Enrichment?">
  If you need to query arXiv, Semantic Scholar, OpenAlex, DBLP, or OpenReview to automatically enrich missing abstracts, DOIs, journal abbreviations, or normalize casing, see the dedicated [Metadata Review & Cleaning](/docs/metadata-review) guide.
</Callout>

## Common Workflows

<Cards>
  <Card title="Add a shared tag">
    Add `literature-review` or a project tag to selected items.
  </Card>
  <Card title="Create a collection">
    Create a new collection around a research topic and move relevant papers into it.
  </Card>
  <Card title="Check metadata">
    Find papers missing DOI, abstract, or publication title.
  </Card>
  <Card title="Organize by theme">
    Group papers into a clearer library structure based on research themes.
  </Card>
</Cards>

## Example Prompts

```text
Review the selected papers and propose a collection structure by research topic. Do not modify Zotero yet.
```

```text
Add the tags deep-research and llm-agent to the currently selected papers.
```

```text
Find papers in this collection that are missing a DOI or abstract, and return a table.
```

## Recommended Workflow

<Steps>
  <Step>
    Ask BibGenie to search or list the candidate papers.
  </Step>
  <Step>
    Ask for an organization plan, including which items will be modified.
  </Step>
  <Step>
    Check that the plan uses the intended papers, collection names, and tags. Ask for changes to the plan if needed.
  </Step>
  <Step>
    Review and approve the proposed write actions when they appear. A larger task may contain several actions; check the scope of each one.
  </Step>
  <Step>
    Check the result in Zotero and ask which changes completed, failed, or were skipped.
  </Step>
</Steps>

Rejecting a proposal leaves that action unapplied. It does not reverse earlier actions you already approved. If a task stops partway through, check what has completed before asking BibGenie to continue.

For example, start with “Add a `methods-review` tag to the selected papers, keep their existing tags and collections, and do not change metadata.” Check the affected papers in the preview, approve the action, and verify the tag in Zotero.

<Callout type="tip" title="Set clear boundaries">
  For batch work, specify scope: "only selected items", "only this collection", or "do not edit metadata, only add tags".
</Callout>

## Use Extra Care With

- Moving many papers at once.
- Removing tags in bulk.
- Overwriting titles, abstracts, DOI, or other key metadata.
- Creating or reorganizing collections across many items.

For these operations, work in smaller batches and ask BibGenie to list the affected items first.
